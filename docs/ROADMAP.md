# Roadmap / Рекомендации

## Приоритет 1 — безопасность
- Перейти на RBAC (roles/permissions) и разграничить доступ к админ‑операциям (экспорт, управление шаблонами, чистка БД).
- Хранить файлы импортов/экспортов только на приватных дисках, выдавать скачивание через контроллер.
- Включить аудит действий админа (кто/что/когда: удаление, экспорт, блокировка пользователей).
- Ужесточить rate‑limits на тяжёлые операции (импорт/экспорт, предпросмотр листов).

## Приоритет 2 — функциональность
- Пресеты экспорта/импорта: сохраняемые профили (колонки, формат, фильтры, лист).
- Очереди для тяжёлых экспортов + статус/готовность/скачивание.
- Версионирование шаблонов и отчёт по качеству данных (ошибки по колонкам, % брака).

## Приоритет 3 — производительность
- Настройка chunk size на импорт/экспорт (отдельно для CSV/Excel).
- Индексация колонок, используемых в фильтрах и экспортных запросах.
- Фоновая очистка старых экспортов/импортов.

## Приоритет 4 — удобство
- Поиск/фильтры в админке по пользователям/задачам/шаблонам.
- Массовые действия (bulk) в админке (экспорт, блокировка, удаление).
- Уведомления о завершении задач импорта/экспорта.
